# CV Agus Faisal Isro'i

Proyek ini merupakan halaman curriculum vitae (CV) pribadi yang dibuat menggunakan HTML dan CSS. CV ini menampilkan identitas, profil, pendidikan, keahlian, proyek, kegiatan, serta bahasa yang dikuasai.

## Preview CV

![Preview CV](preview%20cv.png)

## Struktur File

- `index.html` — struktur utama halaman CV
- `style.css` — styling tampilan CV
- `foto.jpg` — foto profil
- `preview cv.png` — preview tampilan CV

## Cara Menjalankan

1. Buka file `index.html` di browser.
2. Atau jalankan server lokal:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000` di browser.

## Deskripsi Singkat

CV ini dibuat dengan layout sederhana dan rapi agar mudah dibaca di desktop maupun perangkat mobile. Desainnya fokus pada penyajian informasi pribadi dan akademik secara jelas.
